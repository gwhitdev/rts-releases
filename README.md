# RTS Releases

Public binary releases and auto-update manifests for RTS (stable and prerelease channels, desktop and laptop builds).

## Installation & Updates

1. Download the desired Windows x64 .zip from [Releases](https://github.com/gwhitdev/rts-releases/releases) and extract it to a folder.
2. Run Play RTS.cmd (or RtsUpdater.exe) to launch and check for updates on your selected channel.
